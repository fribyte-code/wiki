Sometimes customers forget the password for their booking system.

Often they can change it themselves by using their own admin user.
Unfortunately, that does not always work, because sometimes they forget the
password for the admin user too.

We currently have two customers for whom we provide booking:

[utstyr.bstv.no](utstyr.bstv.no) and [booking.srib.no](booking.srib.no)

Then we have to fix it. This can be done as follows:

1. Go to the relevant booking page and find the "Logg inn" button
1. Log in with our user; the password is either the standard one or can be found in Bitwarden
1. Change the password!
