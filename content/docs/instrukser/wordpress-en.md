#### Logging in

1. Go to https://DOMENE_NAVN/wp-admin.
2. Use the username and password to access the WordPress Dashboard.

#### Installing and changing themes

1. Click "Appearance", then select the "Themes" submenu.
2. Click "Add new theme" to add a new theme.
   - There are several thousand ready-made themes here.
3. Hover over the selected theme and choose "Install".
4. The installed theme will now appear under "Appearance/Themes".
5. Hover over the new theme and choose "Activate".

#### Editing

1. Click "Appearance", then select the "Editor" submenu.
   - Here you can add elements to the page.
2. Click on the image of the website. Here you can add, edit, or delete
   elements on the page.
   - Click the "+" icon in the upper-right corner to add a new element.
   - Hover over an element to bring up a menu, which is used to edit or
     delete the element's content.
   - Click on text to edit the text in the field.
